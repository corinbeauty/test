需求輸入 你 → 產品經理

用自然語言描述想法，產品經理負責整理成清晰規格。

  • 產出 User Story 與完整 PRD
  • 定義功能優先級與成功指標
  • 明確標註 Non-Goals（不做什麼）
  • 初步技術可行性判斷
輸入你的想法描述
輸出PRD + User Story

技術規劃 產品經理 → 架構師

根據 PRD 產出系統設計與技術方案。

  • 系統架構圖（文字或 Mermaid）
  • 技術棧建議（前後端、資料庫、第三方）
  • API 設計草案與資料模型
  • 複雜度與風險點評估
輸入PRD
輸出架構文件 + API 設計

任務拆解 架構師 → 工程師

把功能拆成可在 1–2 小時內完成的小任務。

  • 產生任務清單（含依賴與優先級）
  • 建議使用 GitHub Issues / Linear 管理
  • 每個任務都有明確的完成定義

程式開發 資深工程師主導

標準開發循環，可在 Cursor 中一鍵執行。

  • 讀取任務與相關程式碼
  • 實作功能 + 單元測試
  • 自我 Review（扮演另一位工程師檢查）
  • 產出完整 PR 描述
  • 你只做最終 Code Review 與 Merge
輸入任務描述 + 現有程式碼
輸出可合併的 PR

測試與品質 QA Agent

自動生成測試案例並產出報告。

  • 單元測試 + 整合測試 + 邊界案例
  • 跑測試並產生報告
  • 發現問題直接開 Issue 回工程師
  • 你只看通過率與關鍵 Bug

部署與上線 DevOps Agent

自動化 CI/CD、環境設定與監控。

  • 處理部署、環境變數、資料庫遷移
  • 產出部署檢查清單與回滾方案
  • 上線後自動收集日誌與錯誤

迭代與監控 全 Agent 協作

持續優化，形成閉環。

  • 每週自動產出使用數據摘要
  • 錯誤與效能報告
  • 下一批優先改進建議
  • 你決定下一輪需求，回到第 1 階段
